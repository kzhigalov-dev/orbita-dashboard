# Орбита

Учебная интерактивная панель для организации личного рабочего дня. Пользователь управляет независимыми виджетами задач, погоды, валют, мыслей, заметок, фокуса, привычек, мирового времени и калькулятора. Основной критерий успеха — соответствие заданию wd-task-2: ООП, ES-модули, два внешних API, корректная очистка ресурсов, клавиатурное управление, публикация и доступный Git-репозиторий.
Принятые предположения: русский интерфейс, персональный организатор, без регистрации, локальное сохранение в браузере. Пользователь поручил полностью выполнить задание и разрешил установку всех рекомендованных навыков. Данные погоды общедоступны; задачи никуда не отправляются.
