# Орбита — интерактивная панель управления UI-компонентами

Учебная работа по заданию [wd-task-2](https://needle.voklaf.ru/teacher-portal/course.html?course=web-design&material=wd-task-2). Приложение на чистом JavaScript ES6+, HTML и CSS, без фреймворков и сборщика.

**Автор:** Жигалов Кирилл Александрович

**Сайт:** https://kzhigalov-dev.github.io/orbita-dashboard/

**Репозиторий:** https://github.com/kzhigalov-dev/orbita-dashboard

## Дизайн

По пожеланию пользователя интерфейс выполнен в духе Google Pixel / Material You: тональные пастельные поверхности, крупные живые часы, округлые карточки и кнопки-капсулы. Часы и дата обновляются автоматически; таймер очищается при закрытии страницы. Это самостоятельное оформление учебного веб-приложения. Векторный знак объединяет центральный круг, наклонную орбиту и золотистый спутник; используется в шапке и favicon. Рядом с часами — «Ритм дня»: реальный общий прогресс задач всех списков.

## Возможности

- Четыре типа виджетов: задачи, погода, валюты и цитаты. Допускаются несколько независимых экземпляров.
- Добавление, удаление, сворачивание и перестановка кнопками. Каждый виджет хранит собственное состояние.
- Задачи: добавление, выполнение, удаление, фильтры и прогресс. Общая сводка учитывает все списки, включая свёрнутые. Начальные задачи — редактируемые примеры.
- Погода: пять городов, текущие условия, ощущаемая температура, влажность, ветер и график ближайших 12 часов.
- Валюты: USD, EUR, CNY и GBP к рублю; изменение к предыдущей дате и пересчёт введённой суммы.
- Локальные авторские мысли с обновлением. Виджет цитат не считается API-виджетом.
- Сохранение задач, настроек, порядка и свёрнутого состояния в localStorage. При недоступном хранилище приложение продолжает работать и сообщает об отсутствии сохранения.

## Запуск

Нужен Node.js 20+ для локального сервера и автоматических проверок. Установка зависимостей не требуется.

```sh
git clone https://github.com/kzhigalov-dev/orbita-dashboard.git
cd orbita-dashboard
npm start
```

Откройте http://127.0.0.1:5173. Не открывайте index.html через file://: браузер ограничивает ES-модули.

```sh
npm test
npm run check
```

Можно опубликовать содержимое `dist/` на любом статическом хостинге. Все пути относительные, поэтому приложение поддерживает размещение в подпапке. Основная публикация — GitHub Pages. Workflow `.github/workflows/pages.yml` запускает проверки и публикует `dist/` после обновления ветки main. Настройка создана по [официальной документации GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages). `.openai/hosting.json` сохранён для первоначальной публикации через Sites.

`UIComponent` принимает конфигурацию и реализует общий каркас, render(), minimize() и destroy(). Его приватная коллекция хранит функции удаления слушателей. `listen()` регистрирует обработчик вместе с очисткой. `animate()` управляет короткими Web Animations, отменяет прежнюю анимацию элемента при повторном действии и все оставшиеся в destroy(); при prefers-reduced-motion пространственные эффекты не запускаются.

`APIWidget` наследует общий компонент и управляет жизненным циклом запросов: idle → loading → success / empty / error. Приватные AbortController, счётчик запросов и таймер защищают от гонок, поздних ответов и зависаний. Перед обновлением предыдущий запрос отменяется. Ответ после destroy() не меняет состояние.

`ToDoWidget`, `WeatherWidget`, `CurrencyWidget`, `QuoteWidget` наследуют базовые классы. Данные и действия инкапсулированы в экземплярах. Общий интерфейс render()/serialize()/destroy() позволяет Dashboard одинаково управлять разными классами — это полиморфизм.

`Dashboard` хранит коллекцию, реализует addWidget(widgetType), removeWidget(widgetId), moveWidget(), restore() и save(). Для нового типа добавьте класс и запись в registry; сетка и жизненный цикл останутся прежними.

`main.js` создаёт Dashboard, связывает каталог с добавлением и обновляет общие статусы. `data.js` проверяет внешние данные и нормализует их. `dom.js` создаёт элементы безопасным способом. Обработчики списка задач делегируются на стабильный контейнер. Конвертер сохраняет поля при обновлении курсов. `SelectControl` управляет обоими выпадающими списками: меню выносится за пределы карточки, поддерживает клавиатуру и очищает слушатели через AbortController в destroy().

## Источники данных и ограничения

1. **Open-Meteo** — https://open-meteo.com/en/docs. Прямой HTTPS-запрос к `/v1/forecast`, без API-ключа. Данные модели, а не измерение персонального датчика. Использование учебное, некоммерческое; атрибуция CC BY 4.0 присутствует в виджете. Город выбирается из списка; геолокация не запрашивается.
2. **CBR-XML-Daily** — https://www.cbr-xml-daily.ru/. Сторонний JSON-сервис курсов Банка России, не официальный домен банка. Используется `/daily_json.js`; скрипты JSONP не исполняются. Обязательная обратная ссылка присутствует. Кеш данных — 30 секунд, интервал между запросами всех валютных экземпляров в одной вкладке — минимум 2,1 секунды. Изменение рассчитывается относительно Previous с учётом Nominal. Дата берётся из ответа, включая опубликованный заранее курс следующего дня. Это справочные курсы, не цена покупки или продажи валюты в банке.

Два внешних API действительно вызываются из браузера. Для них явно отображаются загрузка, пустой ответ, ошибка и успешные данные. Тайм-аут — 15 секунд. Доступность API, CORS, лимиты и актуальность данных зависят от внешних сервисов. Ограничение частоты действует в одной вкладке; несколько вкладок и пользователей могут суммарно исчерпать лимит провайдера. Большое число валютных виджетов загружается по очереди.

Внешние ответы проверяются перед использованием. Числовые поля проверяются на конечность, номинал — на положительность, дата — на валидность. Текст вставляется через textContent, SVG-точки формируются только из проверенных чисел. innerHTML не используется. Секретных ключей нет.

Состояние не синхронизируется между устройствами. Приватный режим, очистка браузера или отказ localStorage могут удалить его. До 20 виджетов и 200 задач в каждом списке; текст задачи до 200 символов. Повторная загрузка получает новые API-данные; кеш валют находится в памяти вкладки. Без интернета локальные задачи и цитаты работают, API-виджеты показывают ошибку. Шрифт Roboto загружается из Google Fonts; при отсутствии сети используется системный шрифт.

## Доступность

Семантические кнопки, формы, подписи и нативные checkbox. Выбор города и валюты реализован через combobox/listbox с aria-expanded, aria-selected и aria-activedescendant; стрелки и Home/End меняют активный вариант, Enter выбирает, Escape и Tab закрывают меню. Доступен поиск по первым буквам. Видимый :focus-visible. Статусы сообщаются через role=status / aria-live. Добавление переводит фокус в новый виджет; удаление — в соседний или каталог; перестановка сохраняет фокус. Сворачивание обновляет aria-expanded и скрывает содержимое. Кнопки обеспечивают альтернативу перетаскиванию; само перетаскивание не реализовано, оно опционально по заданию. Учитывается prefers-reduced-motion. На узком экране сетка становится одноколоночной.

Анимации подтверждают действие: добавление и перестановку виджетов, выполнение задачи, смену цитаты, появление меню и получение API-данных. Перестановка использует FLIP: замер исходной и новой позиции, затем переход transform. Логотип делает один короткий поворот при открытии; график прогноза рисуется по полученным данным. Показатели и действия доступны сразу; искусственных задержек нет. CSS-эффекты учитывают prefers-reduced-motion. Дополнительных зависимостей не установлено.

Полное соответствие WCAG не заявляется: специализированное тестирование с экранными дикторами не проводилось. Подробности фактической проверки — в [docs/QA.md](docs/QA.md).
