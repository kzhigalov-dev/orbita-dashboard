# Проверка «Орбиты»

Дата: 5 октября 2026 года. Проверялись исходники и локальная версия в браузере Codex.

## Автоматические проверки

`npm test`: 9 проверок, все проходят.

- Контракт погоды: пустой ответ, некорректные числовые данные, валидный прогноз.
- Контракт валют: пустой ответ, нормализация Nominal, некорректная дата и структура.
- Новый запрос отменяет предыдущий; поздний ответ не перезаписывает новый.
- destroy() отменяет запрос и запрещает позднее обновление.
- HTTP 503, сетевая ошибка, пустой результат и успех различаются.
- destroy() удаляет обработчики и допускает повторный вызов.
- Обновление валют отменяет активный запрос до ожидания ограничения частоты. Этот тест сначала воспроизвёл ошибку, после исправления прошёл.

## Браузерные сценарии

- Оба внешних API вернули реальные данные в локальном браузере.
- Задача добавляется клавишей Enter, отмечается выполненной, отображается фильтром «Готово», удаляется.
- Введённая строка с HTML-тегами отображается буквально; тегов в DOM нет.
- Второй список имеет независимые задачи.
- После изменения порядка и сворачивания перезагрузка восстановила оба состояния.
- Удаление виджета передало фокус соседнему виджету.
- Конвертер: изменение суммы и валюты пересчитывает результат; отрицательная сумма показывает объяснение.
- Быстрая смена города: конечный выбранный город восстановлен; защита от поздних ответов проверена отдельным автоматическим тестом.
- У кнопок есть текст или доступное имя.
- На ширине 390 px ширина документа равна ширине окна: горизонтального переполнения нет.

- После перехода на Google Pixel / Material You проверена ширина 390 px: 4 виджета, горизонтального переполнения нет.
- Кнопка «Другая мысль» обновила текст; после изменения сохранение продолжило работать.

- Широкий экран 1440 px: адаптивная сетка, все четыре вида виджетов отображаются. Консоль не содержит ошибок или предупреждений.
- Impeccable: низкий контраст hover у ссылки перехода исправлен; замечание о популярности Roboto принято как осознанное исключение для заданного пользователем стиля Google Pixel.

- Локальный сервер через npm start запустился без зависимостей, главная страница вернула HTTP 200.

## Границы проверки

Это проверка функциональности и выбранных аспектов доступности, не сертификат WCAG. VoiceOver/NVDA, все браузеры и долговременная доступность внешних API не проверялись. Ошибки сети и пустые ответы воспроизведены автоматическими тестами с управляемыми ответами, а не отказом реальных сервисов. Приложение не обещает синхронизацию или серверное хранение задач.
