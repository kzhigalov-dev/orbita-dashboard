# Проверка «Орбиты»

Дата: 5 октября 2026 года. Проверялись исходники, локальная и опубликованная версии в браузере Codex.

## Автоматические проверки

`npm test`: 34 проверки, все проходят. История предыдущих проверок ниже сохранена.

- Контракт погоды: пустой ответ, некорректные числовые данные, валидный прогноз.
- Контракт валют: пустой ответ, нормализация Nominal, некорректная дата и структура.
- Новый запрос отменяет предыдущий; поздний ответ не перезаписывает новый.
- destroy() отменяет запрос и запрещает позднее обновление.
- HTTP 503, сетевая ошибка, пустой результат и успех различаются.
- destroy() удаляет обработчики и допускает повторный вызов.
- Обновление валют отменяет активный запрос до ожидания ограничения частоты. Этот тест сначала воспроизвёл ошибку, после исправления прошёл.

## Границы проверки

Это проверка функциональности и выбранных аспектов доступности, не сертификат WCAG. VoiceOver/NVDA, все браузеры и долговременная доступность внешних API не проверялись. Ошибки сети и пустые ответы воспроизведены автоматическими тестами с управляемыми ответами, а не отказом реальных сервисов. Приложение не обещает синхронизацию или серверное хранение задач.
