# Учебная работа по веб-дизайну — задание 2

ФИО: **Жигалов Кирилл Александрович**

Название: **«Орбита» — интерактивная панель управления UI-компонентами**

Сайт: https://kzhigalov-dev.github.io/orbita-dashboard/

Репозиторий с исходным кодом: https://github.com/kzhigalov-dev/orbita-dashboard

Приложение реализовано на JavaScript ES6+ с использованием ES-модулей и классов. Доступны независимые виджеты задач, погоды, валют и цитат, их добавление, удаление, сворачивание и изменение порядка. Погода получает данные Open-Meteo, валюты — CBR-XML-Daily. Оформление — в стиле Google Pixel / Material You.

Архитектура, запуск, источники данных, ограничения и описание применения ИИ приведены в README репозитория. Сверка требований — в docs/REQUIREMENTS.md.
